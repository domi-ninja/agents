# Vercel web interface guidelines

Read [the guidelines](references/web-interface-guidelines.md) before implementing or reviewing web UI. Apply the sections relevant to the requested work and respect the project's design conventions and the user's instructions.

For implementation, use the guidelines to guide the affected UI and its states. Keep changes within the requested scope.

For reviews, report concrete findings with file and line references where available, explain the user impact, and suggest a correction. Distinguish verified issues from checks that require browser interaction or measurement. A review request alone does not authorize edits.
