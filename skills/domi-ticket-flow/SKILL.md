# Ticket flow

- When user asks you to make tickets in repo, use the `tickets/` folder, make numbered files. 
- On bottom of ticket file, ask the most pressing question you have for the user, and include a default answer for how you would handle it.
- When working with tickets, make invididual commits per-ticket-completed.
- Move finished tickets to `tickets/done/`. Fix links and commit.
